05 图的职责

效果图、技术平面图、比例稿和分解图回答不同问题

不要让一张图承担所有信息。

表达意图

  • 效果图：比例、姿态、氛围
  • 技术平面图：前后结构与细节
  • 局部放大：工艺和连接

检验：效果图能不能让人一眼看出比例和姿态？看不出，它就只是一张装饰画。

验证可行

  • 纸样：二维尺寸与形状
  • 分解图：内部结构与开合
  • 比例稿：问题与修改证据

检验：效果图和款式图说的是同一件衣服吗？对不上，先停下来改款式图。

为什么要分开一张图承担两件事，两件都会做不好。评审时先问一句“这张图回答哪个问题”——答不出的图不要放进板面。　本周对照你的四类图里，哪一类还完全没有？那就是你现在最大的缺口。

07 细节分类

先判断细节承担什么任务

这四个字母就是微练里要标在每条线旁边的那四个——S 结构 / F 功能 / C 连接 / I 识别。一个细节可以同时占两个字母。

S

结构细节

省道、分割、褶裥改变体积。

F

功能细节

开合、口袋、调节与保护回应使用。

C

连接细节

缝合、包边、叠压决定制作路径。

I

识别细节

重复比例、边缘和材料形成系列记忆。

一个字母都占不上的线，通常是可以删掉的线。纯装饰若不承担识别，就删。大纲说的“细节的情感传递”，在本课程由 I 识别 承担：重复比例、边缘与材料形成系列记忆——那就是情感被传递的方式。图源：Mugler 2026秋冬成衣 · Sacai 2027度假系列 · Noir Kei Ninomiya 2026秋冬成衣 · Chanel 2026秋冬高定｜仅用于课堂细节责任分类观察。

11 细节分析
笔记 ① ｜ 判断句从可见证据写出一条能被反驳的制作假设——它就是本周笔记的第①栏。

结构细节分析：从可见证据到制作假设

像结构分析师一样追踪因果：先记录看得见的关系，再区分责任、假设与待验证证据。

可见

肩部轮廓／袖窿位置

可记录宽肩比例、肩点和袖窿位置；不能由正面照确认垫肩或内部支撑。

部分可见

前中叠门与纽扣

可见前中开合、纽扣数量与排列；内侧扣位和门襟结构仍需技术平面图或分解图证明。

待验证

口袋构造

只能确认袋口的位置与方向；远景照片不足以断言袋型、内部结构和制作成本。

01

看见什么

记录部位、位置、方向、比例、数量和重复关系。

02

承担什么责任

判断主要与次要责任：结构、功能、连接或识别。

03

提出制作假设

推测纸样片、缝合路径、开合和边缘处理，但写明“假设”。

04

补什么证据

寻找后视图、局部近照、技术平面图或分解图进行核对。

课堂规则可见事实用实线；制作推测用虚线；无法确认处必须写“待验证”。

12 构造词汇

二维图与构造词汇必须共同指向同一件衣服

教材图像用于校正专业术语和结构观察，不替代自己的平面图与款式图。这六个词是“六类信息”里“结构线”一格的展开——不是另一套清单。

先指出外轮廓与身体距离，再进入省道、褶、缝、开口和闭合。

18 身体空间｜当代案例

四种身体距离，需要用造型实例同时比较

上周贴合上周离体

贴体｜近零距离

＝上周“贴合”。弹性与省量沿身体曲面分配，服装持续贴近肩、腰、臀。

五类基础训练，以“操作前—过程—结果”建立证据

五类不是五种风格，是五种把体积做出来的办法。每一类都要交同一样东西：操作前的原型 ＋ 操作线 ＋ 结果。

切开展开｜增加下摆

从下摆切开，保持腰线连接并等距展开。

提交证据　展开角度 · 间距 · 新侧缝与下摆线

压缩标记区，把余量转换为褶裥或抽褶。

06分
结构图

照清单画前后两张，同比例、共用一组基准线；只画 8–12 条主结构线，不画缝迹线。例：外轮廓 → 清单上的 ①②③ → 补 ④⑤。清单上没有的线不要加。

04分
细节备注

挑清单里责任最重的一条放大画，只标 位置·做法·尺寸参照。例：②与③的交点放大，标「分割线距肩点约 4cm」。

07分
小样

A4 复印纸对折当前中，剪出肩斜与袖窿，胶带固定立起来。只验证一件事，不做完整衣服。例：验证「落肩分割撑不撑得住肩点外移」。撑不住 → 分割线下移 1cm 再剪一张，两张都留。

04分
证据页

竖拍正／侧／背三张，箭头指出与平面图不一样的地方，各写一句「差在哪·下一步改哪条线」。例：「背面多出余量 → 下一步把后中褶量减半」。写「有点不一样」不算。

证据页＝A4 一页，四格

左上 前后平面图（同比例·基准线对齐）　右上 局部放大（位置·做法·尺寸）　左下 立体 正／侧／背 三张　右下 差异三句（每句带下一步改哪条线）。

四格必须是同一套造型——换题等于重来。

这样算未完成

✗四格不是同一套　✗立体只有正面　✗差异只写「有点不一样」　✗图上出现清单里没有的线

复习思考题

三道题，都要回到本周画过的那张图

教案要求书面作答。不要抄参考答案——每题都用你自己那一套造型举一个例子，指出是第几张图的哪个部位。答不出例子，说明这一条还没学会。

媒介分工效果图与技术平面图为何不能互相替代？
效果图表达设计意图与穿着氛围，允许艺术夸张；技术平面图是制作依据，须以正投影交代前后关系、结构线、开合、缝型与工艺标注。用效果图代替平面图，工艺端无法确定做法；反之则说不清设计意图。
立体验证为什么同一张纸样在不同材料上会得到不同体积？
纸样只规定平面形状与量的分配，体积由材料的刚度、悬垂性、厚度与回弹决定。刚度高的材料维持离体空间，柔软材料在重力下塌陷为顺体。所以纸样必须配合材料实测，记录结果与失效条件后再修正量的分配。
细节责任判断一处细节是否成立，应依据什么？
先判断它承担哪一类责任：结构 S／功能 F／连接 C／识别 I。成立条件是在其责任范围内可被证明——口袋给出最小可用尺寸，开衩说明动作幅度；装饰细节也要说明它控制了哪一处视觉重心。
三题合起来就是本周的一句话：图纸提出结构，立体与细节证明它能成立。
