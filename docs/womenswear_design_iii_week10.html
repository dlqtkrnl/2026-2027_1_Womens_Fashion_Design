02 看·4分　一套里的五原则

一套衣服：六种语言，五条原则

一套里能动的只有六样——廓形、线、色彩、材质、细节、比例。设计，就是决定它们哪里相同、哪里不同、哪里最强。

  1. 统一一个想法领口、口袋、裤脚是同一种白软边——同一样东西出现两次以上
  2. 调和对比要搭桥硬红外套和软白裤之间，靠白边接上
  3. 均衡站得稳上身短而重（红、硬），下身长而轻（白、宽）
  4. 强调只破一处全身只有这一块大红——最强的对比只放一个地方
  5. 节奏视线会走白：领 → 口袋 → 裤脚，一路往下

挑你春夏五套里最弱的一套：五条缺哪条？只改一处补上，再进秋冬。

外套一盖，五条原则换了位置

主题、不变项、第07周排的五个角色——都留下。要改的只是：五条原则落在身上的哪里。

落在哪里

统一同一种颜色、同一种轻薄料→外套上重复同一个细节：领、边、扣
调和轻薄料之间本来不打架→厚外套＋薄里层：用同色或同一条边搭桥

节奏露多少、透多少交替→外套短·中·长交替，厚薄交替

05 看·3分　秋冬必知

转秋冬：先换品类，再记六件事

同一个女装品牌，夏季和秋季各开发八十多款——总数差不多，换掉的是品类。

5→10外套 翻一倍
0→20长袖·卫衣
7→0吊带

你的五套：外套至少出现三次；春夏无袖、吊带那一套，秋冬不能单穿。

最容易漏

② 放量：外套比里层大一圈

肩、袖窿、袖肥、胸围都要放。外套和里层画成一样宽，就是穿不进去。

  1. ①层次两到三层：里层＋中层＋外套
  2. ③长度看外套到胯／膝／踝——决定盖住多少
  3. ④厚薄厚从哪儿来：毛呢、羊绒、絮棉、针织、皮革
  4. ⑤色彩外套面积最大＝主色；亮色只给露出来的一小块
  5. ⑥开合穿着里层要开得到底、扣得上；两层领不能顶住

09 做·10分　步骤1

外套三档：一短、一中、一长

从第09周带来的外套参考 3 张里来。练习册三个人形，一档画一个。

外套画实线，
里层画虚线。
虚线碰到实线＝
穿不进去。

改法只有两个：外套放大，或者里层减一样。

每一档写三行

  1. 1到哪儿胯／膝／小腿／踝——画一条横线；三档不能落在同一条线上
  2. 2怎么开前中开扣／拉链／系带／不扣披着
  3. 3厚还是薄只写一个字

最常碰的三处

  1. 袖泡袖塞不进窄袖
  2. 领两层领顶在一起
  3. 摆里层裙比外套宽

你的不变项要挪一样到外套上——没挪，就是别人的外套。

A03 效果图｜画出厚度

一套效果图里，厚和叠穿怎么画出来

Huakun Zhu 的单套效果图：大衣盖住高领针织，领口露出一截。

  1. 厚看轮廓肩和袖比身体宽出一圈，下摆硬挺——画的是厚料的轮廓，不是线条多
  2. 层看领口和袖口里层高领、外套翻领上下错开，一眼看出几层

你的秋冬效果图里，里层从哪一处露出来？画不出来，回到步骤1看虚线。

A04 教材证据｜色彩故事

色卡不是色彩故事——要落到品类、位置和面积上

教材这张色卡和款式图同框：米、驼、灰、黑占三分之二以上，橙、黄、蓝、红只占少数。

  1. 面积数量比＝面积比中性色铺满衣身，高彩色只出现在手套、局部色块和配饰
  2. 对照步骤4外套＝主色；露出来的那一截＝春夏的颜色；最亮的给最小的一块
