04 概念校正

复制“长相”，还是提取“生成规则”？

先看真实服装，再判断哪些信息能离开原图继续生成新的高级女装造型。

错误路径｜复制完整图形

照搬这一套的蓬大裙形、黑白墨迹和完整搭配，只改变颜色、大小或位置。

01 方向笔势 → 斜向动势

角度、起点和终点可以变化；“运动方向”保持可读。

02 结构骨架 → 离体支撑

固定点、支撑范围和离体距离成为可调变量。

03 表面墨迹 → 疏密层次

不用复制花纹，改用透明度、密度和边界变化。

04 身体体积 → 局部扩张

肩、腰、髋或下摆可以轮换，身体关系仍然一致。

正确路径｜提取可操作关系

用“方向＋固定点＋材料行为＋身体位置”写成规则，再改变尺度、位置与数量。

遮住照片后测试：能否用同一句规则生成3套不同造型？能，才是“元素提取”。

20 失败卡诊断

失败卡诊断

先定位卡片中缺失的字段，再做最小修复；不要直接重画整套设计。

F1｜复制图形

来源传统花纹
观察像花，所以放大贴在肩部
操作放大
问题复制了外形，没有提取结构关系
不可进入造型生成

修复｜从图形改为关系

观察中心固定、四向展开、层层错位
操作悬挂 + 错位 + 重复
变量间距 / 长度 / 层数
验证至少生成3种肩部结构
关系可被系列化

F2｜没有优先级

核心纹样、颜色、材质、故事、轮廓全部保留
问题信息竞争，5套之间无法建立主线
结果每套都像不同主题
删减前不得进入系列

修复｜2 + 2 + 1 分级

核心展开关系 + 错位层次
辅助半透明材质 + 局部硬挺
语境低饱和色
验证遮住来源图仍能说出系列规则
主次关系清晰

F3｜不能扩展

操作只在一件礼服腰部做一次褶皱
变量未定义
问题无法转移到上装、裙装或外套
单件效果，不是系统

修复｜建立变量轴

位置肩 / 腰 / 下摆
尺度局部 / 半身 / 全身
数量1 / 3 / 连续重复
验证同一规则生成至少5套不同造型
可进入系列矩阵

F4｜脱离任务书

造型巨大硬质结构包围手臂
场景需要行走、抬臂、独立穿脱
问题视觉效果与穿着条件冲突
缺少身体测试

修复｜绑定身体条件

固定点肩点与侧腰两处
活动量抬臂90°不受阻
穿脱3分钟内独立完成
验证坯布样衣拍摄正 / 侧 / 动态
证据通过后保留

林芝伊从潮汕嵌瓷中提取支撑、黏合与有序排布，把传统工艺关系转成服装结构和材料实验。

01

解构原工艺

骨架支撑／灰泥黏合／碎瓷有序排布。

02

写成抽象规则

网格承重＋穿孔连接＋硬片按密度排列。

03

转译材料与结构

网格面料、手工编织、瓷片拼接与UV覆膜皮革。

04

验证视觉秩序

蓝、粉、白并置；硬片和柔性织物形成层次与张力。

提取支撑—连接—排布成为可变化的系统。

26 AI协同边界

AI可以扩大候选，不可以替代来源判断

A0人工观察必须先于AI；所有建议都要回到原始证据，被保留、修改或否决。

A0｜人工观察

给证据编号，先写身体位置、方向、重复关系与材料行为。

A1｜AI候选

协助分类词汇、聚类相似关系，并提出尺度或位置变化。

A2｜回看原证据

逐条检查候选是否能在图像、实物或调研记录中被指出。

A3｜人工决定

说明保留、删除与修改理由，再确定层级和下一步验证。

可用分类线条、比例、材料词和细节动词。
词汇归类重复关系聚类参数候选
检查：每一项都能回到证据编号吗？
需说明生成抽象变体时保留提示、版本与筛选过程。
完整提示语版本对照保留／删除理由
检查：人工修改发生在哪里？
禁止复制文化纹样、品牌标识或编造不存在的证据。
文化纹样替换品牌标识挪用虚构来源与工艺
检查：是否制造了无法核验的事实？
提交记录工具、提示、采用内容与人工修改理由。
工具／模型输入与输出版本最终责任人

31 第05周总结

元素不是一张图，而是一套可以继续生成的规则

本周完成了“证据 → 观察 → 抽象 → 分级 → 验证”的元素库闭环。

01 EVIDENCE

证据可追溯

每张卡都有来源编号、局部位置与使用语境。

02 LENSES

六类观察

轮廓、结构、线条、细节、材料、色彩分别判断。

03 SYSTEM

四级分层

核心／辅助／语境／禁用，避免所有元素同时发声。

04 TEST

规则可验证

至少3个变体，并写清变量、不变项和失败条件。
